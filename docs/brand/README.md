# Logos

El logo de MyOrbit es la **órbita de ruta**: una línea que da la vuelta completa con dos estaciones encima. La estación llena es lo hecho y la hueca lo pendiente, el mismo código de estado que usa la app.

- `myorbit-icon.svg`: el logo principal. Placa `logo-coral` con el glifo en `logo-night`. Para el favicon, `apple-touch-icon`, los íconos de la PWA, la barra lateral y el login.
- `myorbit-icon-dark.svg`: la versión invertida (placa night, glifo coral). Para splash screens o fondos coral donde la placa coral se perdería.
- `myorbit-icon-maskable.svg`: sangra a todo el ancho y deja el glifo dentro de la zona segura (80%). Solo para el ícono maskable de Android.
- `myorbit-mark.svg`: el glifo solo, a una tinta con `currentColor`. Para monocromo, sellos, marcas de agua y dentro de UI ya coloreada.
- `myorbit-lockup-light.svg` / `myorbit-lockup-dark.svg`: el ícono con el nombre en Barlow Condensed 600. El texto depende de la fuente: para impresión o fuera de la web, conviértelo a curvas antes de usarlo.
